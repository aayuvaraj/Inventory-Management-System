REVIEW-READY COPY OF RECENT IMS PROJECT

1. Copy your own backend/.env into backend (do not share it).
2. In backend: npm install && npm start
3. In frontend: npm install && npm run dev
4. Open http://localhost:5173 and log in.
5. Test Products, Suppliers, Warehouses, Purchase Orders.

New modules are basic CRUD demos; no automated stock allocation, purchase-order receiving, role-based admin, or deployment is implemented.
This archive deliberately excludes .env and node_modules.
